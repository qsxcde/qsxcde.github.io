很多网站背景里那些缓缓流动的光点，其实几行原生 Canvas 就能画出来。本文拆解一个「会呼吸」的粒子背景，并聊聊它在性能上的坑。

## 粒子从哪来

每个粒子只需维护位置、速度与一个相位。每帧根据相位轻微扰动速度，就能得到类似呼吸的律动感。

## 性能的两个开关

一是用 `requestAnimationFrame` 对齐屏幕刷新；二是粒子数超过阈值时，把静态层预渲染到离屏 canvas，避免每帧重画。

```js
const off = document.createElement('canvas')
// 只画一次，之后整块贴回主画布
```

当你开始关心「每帧省下多少绘制」，动画才真正变得丝滑。
