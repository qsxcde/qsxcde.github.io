## 单屏布局改为「按屏幕高度自适应等比缩放」
- 用户问能否做成根据屏幕大小自适应缩放（之前固定 100vh + overflow:hidden 会在矮屏裁切内容）。
- 新建 `src/composables/useFitScale.js`：`useFitScale(viewRef, stageRef)`。思路——以自然设计尺寸排版（内层 `.stage`），挂载后测量 `stage.offsetHeight`（自然高）与 `view.clientHeight`（可用高 = calc(100vh-152px)），`scale = min(1, 可用/自然)`，对 `.stage` 应用 `transform: scale()` + `transform-origin: top center`；只缩不放（大屏保持 1）。`onMounted` 锁 body 滚动（resize <992 放开），`resize` 用 rAF 防抖重算，`document.fonts.ready` 后重算（防 Noto 字体异步加载导致高度变化）；`onBeforeUnmount` 解锁+移除监听。
- 首页/时间线/标签页三处统一改造：外层 `.home-view/.timeline-view/.tags-view` 仅保留 `height: calc(100vh-152px); overflow:hidden`（移动端 auto+visible），内层包 `<div class="stage" :style="transform scale">`；删除原先 flex:1/min-height:0 与 article-list overflow:hidden。各页 `watch(pagedPosts.length / 路由 query)` 调用 `refit()` 在翻页/筛选后重适配。
- `npm run build` 通过。
- 经验：transform scale 不影响 offsetHeight（布局尺寸不变），测量天然稳定；`scale=min(1,…)` 保证矮屏完整可见、大屏不放大变形。
